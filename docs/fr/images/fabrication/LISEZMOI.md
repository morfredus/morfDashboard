# Images de fabrication du module pi4fred

Déposer ici les 13 photos, renommées selon la table ci-dessous. Le document
[`../../FABRICATION-MODULE-PI4.md`](../../FABRICATION-MODULE-PI4.md) les référence
par ces noms, dans l'ordre logique de construction.

Formats acceptés : `.jpg` (recommandé). Si tu changes d'extension, adapter les
liens du document.

> Traitement appliqué aux photos : légère correction (lumière, contraste,
> saturation, netteté). `01-materiel` et `07-ecran-capteur-monte` ont été
> recadrées en bas pour retirer un hors-sujet.
